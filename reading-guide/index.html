这个博客记录我的论文阅读、代码实践和研究想法。目前主要关注 Agent 的 Token 效率，也保留了此前在 LLM 推理系统和幻觉研究上的笔记。

Agent 效率：完成一个任务需要多少成本

关心的不只是单次调用用了多少 Token，还包括整条任务轨迹中的上下文读取、工具调用、重复探索和重试。

  • Skill 检索、压缩与复用：从技能的组织和检索入手，整理按需加载、文本压缩与经验复用的方法。
  • 上下文管理与任务总成本：继续看活动上下文、历史信息恢复、缓存复用和推理预算，以及这些方法对任务成功率的影响。

想先建立整体认识，可以从第二篇开头的目标与指标读起；更关心 Skill 工程实现，可以从第一篇开始。

LLM 系统：理解推理过程中的计算与存储

这一组笔记从 vLLM 的运行和源码阅读，逐步走向 KV Cache 管理、树结构推理和 CPU-GPU 协同。

  • vLLM 入门记录：跑例程、看调度和缓存管理，再尝试动手修改。
  • DeFT：树结构推理与 KV Cache 复用：理解共享前缀、注意力计算与 IO 之间的关系。
  • LLM 推理优化探索：KV Cache、稀疏计算与 CPU-GPU 协同：串起基础概念、相关论文和实践中的问题。

幻觉研究：检测、解释与缓解

这部分包含早期的综述阅读，以及几种代表方法的精读笔记。

  • 多模态大模型幻觉综述整理：先了解问题类型、成因和评估方式。
  • SelfCheckGPT：通过多次采样结果的一致性检测幻觉。
  • OPERA：从注意力模式和解码策略理解多模态幻觉。
  • TruthX：通过编辑模型内部表示探索幻觉缓解。

其他学习记录可以从标签按主题查找，或在归档中按时间浏览。
